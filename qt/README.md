# WinSCP Qt 1.0

Windows 文件管理器，使用 C++20、Qt 6 Widgets、libssh2 和 Qt Network。应用没有官方网站入口、更新检查、广告、捐赠、遥测或作者介绍。网络访问仅用于用户配置的服务器连接及其协议操作；帮助菜单提供本地快捷键和日志。

浅色和深色主题均以中性灰区分工作区、标题栏、选中状态和主操作。文件面板采用 16px 图标、20px 文件行高和 26px 工具按钮，终端使用近黑背景。主题颜色集中定义在 `Theme.cpp`，共用 `common.qss` 的布局与状态样式，图标按显示缩放比例绘制。文件名过长时中间省略，完整路径可通过悬停查看；可编辑的路径历史最多显示 8 项。主窗口分割条拖动时按 Esc 恢复原位置，双击恢复等分，拖入边缘 20% 区域后收起较小面板，可向内拖动分割条恢复。

## 功能

- SFTP、SCP、FTP、显式/隐式 FTPS、HTTP/HTTPS WebDAV，以及本地文件浏览。
- 双栏文件管理、`..` 上一级目录、可点击的各级路径、路径历史、筛选、隐藏文件、拖放上传下载、新建、重命名、递归删除、属性、Unix 权限和符号链接。
- 工具栏下方的会话标签页支持同时打开多个站点，每个标签保留独立的连接、双端目录和终端。最后一个无名称标签打开与启动时相同的新增／登录窗口；取消登录保持当前标签。标签上的关闭按钮只关闭该会话，后台传输继续使用统一队列。
- 本地目录在后台枚举，快速切换目录时丢弃过期结果，不阻塞窗口加载；本地磁盘容量随目录加载更新。
- 启动时显示登录窗口，左侧选择站点，右侧输入协议、主机、端口、用户名和密码；保存站点时单独设置名称与是否保存密码，高级区域提供私钥、TLS 和连接设置。支持最近会话、按站点恢复上次使用的本地和远程目录、Windows DPAPI 密码保存、SSH 主机密钥验证。
- 上传、下载和双击远程文件所需的下载共用传输进度窗口。队列空闲后加入首个任务即开始新一轮，窗口只显示本轮任务。全部成功后自动关闭，重新打开时显示空状态；本轮有失败或取消时保留结果，可右键查看详情。支持并发任务、取消、冲突确认、修改时间和权限保留。
- 传输进度每 100 毫秒合并更新；任务结束后释放文件列表和连接凭据。SFTP/SCP/FTP/FTPS 上传先写入同目录临时文件，成功后替换目标；取消或失败保留原目标，并尝试清理临时文件。此流程要求目标目录可写，服务器支持替换重命名。连接中断导致清理失败时，可在服务器恢复后删除 `.winscp-upload-*` 文件。
- 本地到远程、远程到本地及双向目录比较，预览后同步。递归同步包含空目录，缺失目录作为一个递归任务处理；删除多余目录包含其内容。类型冲突、大小写冲突、无法无损映射到 Windows 的文件名或无效目录响应会中止比较，符号链接及其子路径不参与同步。
- 内置 UTF-8 文本编辑器，保存远程文件后上传，上传成功后关闭；失败时保留编辑内容并允许重试；深色和浅色主题。

## 导航、刷新与打开文件

路径栏的各级目录可以直接点击；铅笔按钮或 Ctrl+L 可输入完整路径。文件列表中的 `..` 返回上一级，不参与上传、下载或删除。本地与远程面板之间拖放文件或目录会执行真实传输，放到文件夹行时以该文件夹为目标，放到空白处时以当前目录为目标。

远程路径保留文件名中的空格和反斜线。下载时处理 Windows 禁止字符、设备保留名和结尾空格或点；同一任务中映射后重名的文件会在写入前报错。下载不写入目标目录内已有的符号链接或目录联接。本地重命名不覆盖已有的其他文件或目录；本地复制不允许复制到自身或其子目录。

远程面板右上角的“自动刷新：开／关”控制每 2 秒在后台读取当前目录，开启时立即刷新。列表只更新新增、删除和属性变化的文件，不显示加载条或重置列表，保留选择、滚动位置和正在输入的路径；加载、文件操作或菜单打开期间暂缓刷新。按钮提示显示上次成功刷新时间，失败时显示“重试”并继续定时尝试。站点编辑不提供初始目录选项，成功浏览的双端目录自动记忆，重新打开站点时恢复；记忆的远程目录不存在时回到服务器主目录。

双击远程文件通过统一传输窗口下载到程序旁的 `downloads/<缓存标识>/content/`，根据内容识别文本，以内置编辑器打开日志、无扩展名文件和文件符号链接，保存后上传到原远程路径；二进制文件使用系统关联程序打开。内置编辑器支持不超过 32 MB 的 UTF-8 文本，保存时保留 BOM 和换行格式。右键“编辑”也可直接使用内置编辑器。缓存通过协议、服务器、端口、用户、完整路径、大小和修改时间区分，每次打开都重新检查远程属性，并校验本地大小和修改时间；远程缺少修改时间时不复用缓存。下载后再次检查远程属性；下载期间继续增长的文本可作为只读快照查看，不复用其缓存，也不允许上传覆盖新日志；其他源文件变化会提示重新打开。服务器内容变化但大小和修改时间均未变化时，无法仅靠这些属性识别。

“首选项 → 传输 → 远程打开缓存保留”设置缓存保留天数，默认 7 天，从最后打开时间计算。在启动、打开文件、修改设置以及每小时检查时清理过期缓存，只处理程序管理的缓存子目录。

## 终端

连接 SFTP/SCP 服务器后，文件管理和底部终端自动打开。底部面板不能折叠，可拖动分隔条调整高度；Ctrl+T 或面板的新建按钮增加终端标签。

文件浏览与所有终端标签复用同一个 SSH 会话及 TCP 连接，仅打开独立的 PTY Shell 通道，不重新登录。libssh2 的操作统一在文件会话工作线程执行，终端通过定时器读取；文件操作期间暂缓终端轮询。后台传输任务使用独立连接，避免大文件传输阻塞交互；默认要求已在文件面板确认过服务器的主机密钥。

关闭终端异步执行。每个终端等待界面消费的输出限制为 256 KB，达到上限时暂停读取，保留 SSH 流量控制；超长控制序列会被丢弃。历史行只存储内容和样式所需的单元格，释放多余容量；Latin-1 字符共享静态存储，组合字符仍可独立修改。WebDAV 会话复用 HTTP 连接，请求、切换和断开串行执行，过期会话结果不会更新当前界面；下载超时或长度不完整时不替换本地文件。FTP、WebDAV、SFTP、SCP 的编辑读取均限制为 32 MB。

支持 UTF-8、中文输入法、Tab 补全、方向键、Ctrl+C 等控制键、复制粘贴、括号粘贴、滚动缓冲区、字体缩放、ANSI 16/256/真彩色、光标、滚动区域、备用屏幕和 PTY 尺寸同步。终端获得焦点时，控制键发送给远端。关闭一个终端不关闭文件连接；断开或切换文件会话会关闭所属终端。FTP/FTPS/WebDAV 不支持 SSH Shell。

## 构建与发布

依赖 Windows 10/11 x64、Visual Studio 2022、Qt 6.5+、CMake 3.21+ 和 vcpkg 的 libssh2/OpenSSL。默认路径为 `C:\environment\Qt\6.10.3\msvc2022_64` 和 `C:\environment\vcpkg`，可通过 `WINSCPQT_QT_ROOT`、`VCPKG_ROOT` 或脚本参数覆盖。

```powershell
.\qt\scripts\build.ps1 -Configuration Debug
.\qt\scripts\deploy.ps1 -PackageName WinSCPQt-win64
```

开发程序在 `qt/build/Debug/WinSCPQt.exe`。默认便携发布包在 `qt/dist/WinSCPQt-1.0.0-win64.zip`，同时生成同名 `.zip.sha256` 校验文件。解压后运行 `WinSCPQt.exe`；程序目录下的 `portable.ini` 使配置保存在 `data/`。不要覆盖已有便携目录中的 `data/` 或 `downloads/`。

生成便携包和当前用户安装程序：

```powershell
.\qt\scripts\deploy.ps1 -PackageName WinSCPQt-1.0.0-win64-portable
.\qt\scripts\installer.ps1 -CompilerPath "C:\Program Files (x86)\Inno Setup 6\ISCC.exe"
```

安装程序构建需要 Inno Setup 6.3+，也可通过 `INNOSETUP_COMPILER` 或 `PATH` 指定编译器。脚本默认使用 `qt/dist/WinSCPQt-1.0.0-win64-portable/`，拒绝打包包含 `data/` 或 `downloads/` 的目录，输出 `qt/dist/WinSCPQt-1.0.0-win64-setup.exe` 和同名 `.sha256` 校验文件。安装默认无需管理员权限，程序位于当前用户的 `AppData/Local/Programs/WinSCPQt/`，提供开始菜单快捷方式和可选桌面快捷方式。安装版不包含 `portable.ini`，配置保存在 Windows 用户应用配置目录；卸载保留配置和下载文件。

```powershell
WinSCPQt.exe
WinSCPQt.exe --url "sftp://user@server:22/home/user"
WinSCPQt.exe --demo
WinSCPQt.exe --demo --screenshot preview.png
```

支持 `sftp://`、`scp://`、`ftp://`、`ftps://`、`webdav://`、`https://`。`insecure=1` 关闭 TLS 证书验证，`implicit=1` 使用隐式 FTPS。默认配置使用 Windows 应用配置目录；`WINSCPQT_HOME` 可覆盖配置和数据目录。

## 验证

```powershell
.\qt\tests\run_integration_tests.ps1 -Configuration Debug
```

需要 Docker Desktop 的 Linux 容器。脚本构建 `winscpqt-tests:local`，创建仅向本机暴露端口的 `winscpqt-tests-<PID>` 容器，运行协议测试服务和真实 OpenSSH。结束时自动删除测试容器，不创建持久 Docker volume。测试输出和服务日志保存在 `qt/build/integration-*`。

测试覆盖五种协议的连接、列表、上传、下载和删除；递归传输队列；同步；终端屏幕和按键；SFTP/SCP 与两个终端的连接身份一致性；同时读写文件；关闭 Shell 后继续浏览；断线与重连；真实 OpenSSH 的 PTY 尺寸、Ctrl+C 和 vi 备用屏幕；主窗口自动打开终端及切换到 FTP；路径导航和上一级目录；自动刷新开关、远程新增/修改/删除、失败重试、保留选择与界面位置、保留路径输入和 FTP 无终端刷新；拖放事件触发真实上传下载；远程打开缓存复用、失效和过期清理；中文无扩展名日志与符号链接的打开和保存；按站点恢复目录。`ctest --test-dir qt/build -C Debug --output-on-failure` 运行终端与界面单元测试，包含站点保存、密码保存选项和深色图标验证。

运行时回归覆盖 WebDAV 请求中的断开与会话切换、超时下载保留原文件、编辑大小限制、异步关闭终端、过期本地目录结果和传输批次切换；真实 OpenSSH 测试验证终端输出达到缓冲上限时暂停读取，界面消费后继续接收完整输出。

核心回归覆盖路径保真、Windows 文件名映射冲突、目标目录联接保护、重命名与本地复制的数据保留、时间戳开关、主机密钥保存失败、编辑上传失败后重试、空目录同步、大小写及类型冲突、双向同步的时间选项，以及 WebDAV 响应截断、属性失败和目录外路径。协议测试逐字节校验大文件，验证下载取消及长度不足时保留原文件、上传取消后的临时文件清理；FTPS 测试服务限制发送速率，覆盖传输中的短暂停顿。

## 范围与限制

- 不是原版 WinSCP 的全部功能移植：不含 S3、.NET 程序集、原版脚本语言、会话导入和主密码。
- SCP 使用 SSH exec 的 POSIX 命令及文件流，需要服务器提供相应命令，不适用于受限的纯 SCP 协议端点。
- 不支持断点续传、FTP 主动模式、SSH 压缩、代理转发、跳板和端口转发。
- WebDAV 使用服务器的 PUT 写入语义；取消或断线后的远程文件状态取决于服务器。FTP/FTPS 不通过文件符号链接上传；SCP 的文本目录列表不能可靠表达所有含换行的文件名，遇到无法完整解析的列表会报错。
- 终端实现 VT/xterm 常用子集，不具备 Xshell 的全部协议、会话和鼠标报告功能。

## 结构与许可

`src/core` 为协议接口、会话控制与配置；`src/proto` 为协议实现；`src/ssh` 为 SSH 连接；`src/terminal` 为 PTY、屏幕解析和渲染；`src/ui` 为界面；`src/transfer` 和 `src/sync` 为传输与同步。
